Картинная галерея

Консольное приложение для управления картинной галереей

## Описание системы

Система позволяет:
- Управлять экспонатами (картинами, скульптурами и другими произведениями искусства)
- Организовывать постоянные и временные выставки
- Покупать билеты на выставки
- Оставлять отзывы с рейтингами
- Фильтровать и искать экспонаты по автору, категории и году создания
- Многопоточная обработка коллекции экспонатов

Пользователи в бд (
Admin: Имеет полный доступ ко всем функциям системы, включая управление пользователями, экспонатами, выставками и покупку билетов.
Manager: Может управлять экспонатами, выставками и тегами, но не имеет прав на управление пользователями и покупку билетов.
Customer: Может только просматривать контент, покупать билеты и управлять своими собственными отзывами и билетами.)
