# Картинная галерея

Консольное приложение для управления картинной галереей на основе данных Третьяковской галереи.

## Описание системы

Система позволяет:
- Управлять экспонатами (картинами, скульптурами)
- Организовывать постоянные и временные выставки
- Покупать билеты на выставки
- Оставлять отзывы с рейтингами
- Фильтровать и искать экспонаты по автору, категории, году
- Многопоточная обработка коллекции экспонатов

## Структура пакетов

### `com.example.gallery.models`
Модели данных:
- `User` (абстрактный) + `AdminUser`, `ManagerUser`, `CustomerUser` - пользователи с ролями
- `Author` - авторы произведений
- `Category` - категории экспонатов
- `Exhibit` - экспонаты (картины)
- `Exhibition` - выставки (постоянные и временные)
- `Review` - отзывы посетителей
- `Ticket` - билеты на выставки

### `com.example.gallery.repository`
Интерфейсы репозиториев для работы с данными (CRUD операции).

### `com.example.gallery.repository.impl` (в том же пакете)
In-Memory реализации репозиториев (хранение в HashMap).

### `com.example.gallery.service`
Бизнес-логика. Каждый сервис отвечает за одну сущность:
- `AuthService` - аутентификация
- `UserService` - управление пользователями
- `AuthorService`, `CategoryService`, `ExhibitService`, `ExhibitionService` - управление сущностями
- `ReviewService`, `TicketService` - отзывы и билеты
- `MultiThreadService` - многопоточная обработка

### `com.example.gallery.console`
Консольный интерфейс (меню):
- `AuthMenu` - вход/регистрация
- `MainMenu` - главное меню
- `ExhibitMenu`, `ExhibitionMenu`, `ReviewMenu`, `TicketMenu` - меню сущностей

## Роли пользователей
- **ADMIN** - полный доступ
- **MANAGER** - управление экспонатами и выставками
- **CUSTOMER** - просмотр, покупка билетов, отзывы
