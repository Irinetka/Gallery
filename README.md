Картинная галерея

Консольное приложение для управления картинной галереей

## Описание системы

Система позволяет:
- Управлять экспонатами (картинами, скульптурами и другими произведениями искусства)
- Организовывать постоянные и временные выставки
- Покупать билеты на выставки
- Оставлять отзывы с рейтингами
- Фильтровать и искать экспонаты по автору, категории и году создания
- Многопоточная обработка коллекции экспонатов
